## 填写示例

```
【Bug 修复】

1. [FIX] 候选人列表 AI 评分列显示 0/10
   现象：无评分的候选人显示 "0/10"，看起来像 0/100
   复现步骤：进入候选人管理页 → 查看无评分候选人
   涉及页面/模块：Candidates.jsx
   预期正确行为：无评分显示 "--"

【新增需求】

1. [NEW] 支持 Excel 批量导入岗位
   描述：系统管理页岗位 Tab 增加 Excel 导入按钮
   涉及页面/模块：System.jsx + server/routes/system.js
   期望效果：上传 .xlsx 自动解析并入库，显示导入条数
```

## 分类速查

| 标识 | 含义 | 何时使用 |
|------|------|---------|
| `[NEW]` | 新增需求 | 当前不存在的功能、增强 |
| `[FIX]` | Bug 修复 | 已有功能行为不符合预期 |
| `[Q]` | 问题澄清 | 不确定、需要说明流程 |

> 填好后直接发给 Agent，会按工作流：拆解 → 分类 → 依赖分析 → 排序输出执行计划。
> 详细流程见 `sub/plan.md`。
